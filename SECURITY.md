# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to **contact@getmiroir.xyz**. Do not disclose them publicly before they are fixed.

Include as much of the following as you can:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- The affected version (shown in the desktop app, or by running the binary with `-version`)
- Your operating system and how the service is run (desktop app, background service or Docker)

Never include your own API keys, private keys or other secrets in a report.

## What to expect

- We acknowledge your report and keep you informed of our progress.
- Fixes are shipped in the next release, and published here as part of that release.
- We are happy to credit you once the fix is released, unless you prefer to stay anonymous.

## Supported versions

Only the latest release receives security fixes. Please make sure you are running it before reporting.
